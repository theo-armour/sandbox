# Daily AI Briefing

A clean, mobile-responsive website for daily AI news and updates.

## Features

- **Home Page**: Introduction to Daily AI Briefing and its target audience
- **News Page**: Curated AI headlines with source links and timestamps
- **Mobile-First Design**: Fully responsive layout that works on all devices
- **Simple Navigation**: Easy-to-use navbar for seamless browsing

## Target Audience

- Students & Researchers
- Industry Professionals
- Developers & Engineers
- AI Enthusiasts

## Pages

- `index.html` - Home page with site introduction
- `news.html` - Daily AI news headlines
- `styles.css` - Responsive styling

## Usage

Simply open `index.html` in a web browser to view the site locally.

## Design

- Clean, modern interface
- Purple/indigo color scheme
- Card-based layouts
- Smooth hover animations
- Mobile-responsive breakpoints at 768px and 480px
