### 1. The Intention Clarifier

**Start here.** For when you have a fuzzy sense of wanting something but can't articulate it clearly enough to act. This is foundational—if you don't know what you actually want, no amount of task management will help.

### 2. The Translation Layer

**The utility knife.** Paste any brain dump and get structured tasks back. Works for meeting notes, voice memos, scattered thoughts—anything messy that needs to become actionable.

### 3. The Sub-Agent Task Specification

**For delegation.** Creates hand-off documents tight enough that an autonomous agent can execute without supervision. The more complete the spec, the safer the autonomy.

### 4. The Daily Briefing

**Morning ritual.** Start each day with context loaded. Works best if you have calendar access, but useful even without.

### 5. Meeting Processing

**Before and after meetings.** Pre-meeting: load context and set intentions. Post-meeting: extract outcomes and update files.

### 6. Weekly Review

**Sunday ritual.** Step back from execution to see patterns, adjust priorities, and set up the coming week.

### 7. End-of-Day Reconciliation

**Evening ritual.** Close loops, update files, set up tomorrow. The habit that keeps the system from rotting.

### 8. The Memory Scaffold

**Not a prompt you run—a file you maintain.** This is the template for your CLAUDE.md (or AGENTS.md) file. The agent reads it at the start of every session.
