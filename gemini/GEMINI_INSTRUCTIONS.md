# Gemini Code Assist Instructions

## Coding Style
- **Naming**: Use camelCase for variables and PascalCase for classes.
- **Comments**: Explain "why", not "what". Use JSDoc for function signatures.
- **Error Handling**: Prefer minimal error logging, use `console.error`.
- **Syntax**: Use ES6+ features (arrow functions, template literals). Prefer `const` over `let`.

## Tech Stack
- **Frontend**: Semantic HTML5, CSS3 (Flexbox/Grid), Vanilla JavaScript (no frameworks).
- **Testing**: Use standard library assertions.

## Response Guidelines
- Be concise.
- Always provide JSDoc type hints for JavaScript.
- When refactoring, prioritize readability over extreme brevity.
