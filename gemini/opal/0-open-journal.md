## Countdown Timer

Create a single-file HTML application that functions as a custom countdown timer.

### Features
*   **Display**: Easy-to-read digital clock showing MM:SS.
*   **Input**: An on-screen numeric keypad (0-9) for entering minutes and seconds. Input should behave like a microwave timer (digits shift left).
*   **Controls**:
*   **Start**: Begins the countdown.
*   **Pause**: Freezes the timer.
*   **Reset**: Stops the timer and clears the input to 00:00.
*   **Alerts**: Display a visual indicator (e.g., background color change) and a browser sound when the timer reaches zero.
*   **Styling**: Minimalist, centered layout with distinct buttons for the keypad and controls.
* **screen size** responsive design for desktop and mobile browsers.
