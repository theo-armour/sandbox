## Editing links

Links live in `newwwtab-data-default.md`.

* Click ✏️ to turn on edit mode, then click any link or section title to open the data file at that line (VS Code when local, github.dev on the web). Click ✏️ again to go back to normal.
* To add a page: in edit mode, drag **📌 +NewwwTab** to the bookmarks bar (once). On any website, click that bookmark to copy `- Page Title https://url`, then paste it into a section.
