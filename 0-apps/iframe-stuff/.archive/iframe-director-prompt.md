* In this folder, create a file named iframe-director.html.
* This file is used to update the URLs of the iframes in iframe-stuff.html.
* The page has a text input for each iframe, and an "Apply" button. The user can enter a new URL for each iframe and click "Apply" to update the iframes in iframe-stuff.html.
* The page also has a "Reset" button that resets the URLs to their defaults.
* The URLs are saved to localStorage so that they persist across page reloads. When the page loads, it should read the URLs from localStorage and populate the text inputs accordingly.
