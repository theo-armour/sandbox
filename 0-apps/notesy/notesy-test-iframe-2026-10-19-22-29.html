🧪 Notesy Test Harness

Two instances of notesy.html share one scratch file:

Edit one side ~ the other shows “Updated from GitHub” within 15 seconds (sooner on click). Edit both sides quickly to trigger the conflict prompt.

~ or open another file via the hash: #https://api.github.com/repos/owner/repo/contents/path

rapid concurrent writes to the scratch file ~ tests conflicts (409) and GitHub's rate limit (403). Uses ~that many of your hourly 5,000 and may briefly trip the secondary limit (~1 min).

📋 Test checklist
  • Load: file title, byte count, tooltip on the title shows the last commit time
  • No phantom saves: touch nothing for a minute ~ no new commits appear on GitHub
  • Save: type on the left, wait for “Saved:” ~ the right shows “Updated from GitHub”
  • Conflict: type on both sides within one autosave tick ~ the slower side prompts; Cancel pauses its autosave, OK overwrites
  • Bad hash: open with #foo ~ “Bad hash” message, no console error
  • Token: hit “🔑 test token” ~ shows the user, scopes, write access and rate limit, or flags a bad token
  • Rate limit: hit “💥 burst write” ~ one 200, many 409 conflicts; raise the count until a 403 appears
  • Bad token: run localStorage.setItem("githubAccessToken","bad"), then “🔑 test token” flags 401; reloading an instance shows “Load failed (401)” and clears it for re-entry
