# Hello World Demo ✨

A zippy, interactive "Hello World" demo with animations and sparkle effects.

## Features

- **Gradient background** - Purple to violet gradient
- **Animated greeting** - Waving hand emoji
- **Interactive button** - Click to trigger effects
- **Sparkle explosion** - Colorful particles fly across the screen
- **Message rotation** - Heading cycles through fun messages
- **Button feedback** - Visual pulse on click

## How to Use

Open `hello-world.html` in any modern browser. Click the "Click Me!" button to see:
- Heading text changes to random encouraging messages
- Button pulses/scales
- 20 colorful sparkles animate across the screen

## Tech Stack

- Vanilla HTML, CSS, JavaScript
- Single-file format (no dependencies)
- ES6 features (arrow functions, template literals, const/let)
- CSS animations and transitions
- Functional programming style

## Code Highlights

- **createSparkles()** - Main function that handles all click interactions
- **Animations** - Pure CSS with @keyframes (fadeInUp, wave, sparkleFloat)
- **Random colors** - Array of sparkle colors for variety
- **Timed cleanup** - Sparkle elements auto-remove after 2 seconds
