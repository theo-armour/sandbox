# Grid Paper Prompt

**Create a printable 5mm grid paper for US Letter size (8.5" × 11") as a single HTML file.**

Requirements:
- Use SVG for the grid pattern
- 5mm square grid using a repeating pattern
- Light gray grid lines (#bbb), thin stroke (0.3)
- Quarter-inch (0.25") white border/margin on all sides of the grid
- Print exactly one page (no page breaks, overflow hidden)
- Zero browser margins using @page rules

Add an address block in the upper right area:
- Left-aligned text starting around 5.2" from left edge
- Monospace font (Cascadia Mono, Consolas fallback)
- 14pt, dark gray (#333)
