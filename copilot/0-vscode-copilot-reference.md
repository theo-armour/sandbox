# VSCode Copilot Reference

## Slash commands

* /help
* /init to copy github/copilot-instructions.md — active Copilot instructions
* Possible: /explain, /fix and /doc

The slash commands are shortcuts for specific actions on code, not for entering a help session.


## @ commands

Given your vanilla JS / GitHub Pages workflow:

**`@workspace`** — Most useful for you. Ask questions across all your repos at once, e.g.:
* "Where do I handle the GitHub API fetch in TooToo?"
* "Which files use the CONFIG object?"
* "Show me all the places I render markdown"

**`@web`** — Second most useful. Great for:
* MDN API questions ("does `fetch` support X in all browsers?")
* GitHub REST API changes or rate limit details
* Checking if a CSS feature has broad enough support

**`@vscode`** — Handy occasionally:
* "How do I set a keybinding for X?"
* "Where is the setting to word-wrap in the editor?"
* "What extension handles Markdown preview?"

**`@github`** — Worth knowing about:
* Ask about your own repos, commits, PRs, issues directly from chat
* e.g., "What changed in my last commit to pushme-pullyou-tootoo?"

**Less relevant for you:**
* `@terminal` — You rarely run build commands
* `@azure` / `@docker` / etc. — No backend infrastructure in your stack

**Best daily combo:** `@workspace` to navigate your code, `@web` when you hit a browser API question.
